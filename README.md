# Data Science Internship – February 2026
## Task 7: Object-Oriented Programming (OOPs)

### Overview
This repository contains Python solutions for six real-world problems as part of the Data Science Internship – February 2026.

The assignment demonstrates Object-Oriented Programming concepts, including classes, objects, constructors, instance attributes, and methods.

### Problems Covered

1. **Smart Light Controller** – Controls a smart light and displays its ON/OFF status.
2. **Employee ID Card System** – Stores and displays employee details.
3. **Mobile Contact Record** – Saves and displays contact information.
4. **Product Price Tag Generator** – Stores product information and generates a formatted price tag.
5. **Movie Rating Display System** – Stores and displays movie details and ratings.
6. **Delivery Address Manager** – Stores and displays customer delivery information.

### Technologies Used
- Python 3
- Jupyter Notebook / Google Colab
- Object-Oriented Programming (OOP)

### OOP Concepts Demonstrated
- Classes and objects
- `__init__()` constructor
- `self` keyword
- Instance attributes
- Instance methods
- Object creation and method calls

### Project Structure
- `README.md` – Project documentation
- `.ipynb` notebook – Python solutions for all six problems

### How to Run
1. Clone or download this repository.
2. Open the notebook using Jupyter Notebook or Google Colab.
3. Run the cells in order.
4. Review the outputs for all six problems.

### Learning Outcomes
- Understand how to create classes and objects.
- Store information using instance attributes.
- Define methods to perform operations on objects.
- Apply OOP concepts to practical applications.
